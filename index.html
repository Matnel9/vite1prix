    Comment ça marche

    1. Vous cherchez un produit

      Par son nom, son code-barres ou un lien Amazon. Si plusieurs modèles correspondent, vous choisissez le bon.

      Chaque produit a un code EAN unique. On compare ce code, pas le nom : pas de confusion entre couleurs, capacités ou accessoires.
